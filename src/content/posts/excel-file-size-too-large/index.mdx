A workbook's visible rows do not account for everything saved inside it.
Pictures, formatting and cached data can matter more than the table on screen.
More explanations are in [Excel & Office](/topics/excel-office/).

<Callout type="note" title="Correction, 27 October 2026">
  This page previously gave untested clean-up steps and implied that a large worksheet part
  proved unwanted content. It now explains the possible causes and links to Microsoft's
  instructions. No workbook reduction benchmark is claimed.
</Callout>

## A workbook contains several kinds of content

Microsoft's [SpreadsheetML structure reference](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/structure-of-a-spreadsheetml-document)
describes separate parts for worksheets, shared strings, styles and pivot data.
An `.xlsx` package represents more than the rectangular values visible in one
sheet. Its internal structure can help explain size, but editing those parts
is a different task from editing a cell in Excel.

A large worksheet part tells you where some of the content is stored. It does
not distinguish necessary business data from redundant formatting by itself.
Likewise, a media part represents image content; its size alone does not tell
you whether the image can be removed without changing the workbook's purpose.

## The used range can extend beyond the current data

Excel tracks a used area for each sheet. Formatting and previous edits can
leave that area larger than the current table. Microsoft's
[performance guidance](https://learn.microsoft.com/en-us/office/vba/excel/concepts/excel-performance/excel-tips-for-optimizing-performance-obstructions)
discusses excess used ranges and the effects of workbook structure.

That makes the last used cell useful evidence, but it is not a licence to delete
everything beyond the visible table. Formulas, references or intentional formats
may depend on those cells. A repair needs a recoverable copy and evidence that
the workbook still gives the correct results afterwards.

## Formatting can add content without adding values

A blank-looking cell can still carry formatting. Excess formatting and
conditional-formatting rules can make a workbook more complicated than its data
suggests. Whole-column formatting should not be described as always creating
one million separate saved cell records; storage depends on how Excel represents
that formatting.

File size and calculation speed are also different measurements. A slow workbook
may have expensive formulas even when its saved file is small. An image-heavy
file can be large without those images explaining formula recalculation time.

## Pictures and pivot caches have their own trade-offs

Microsoft's [file-size guidance](https://support.microsoft.com/en-us/excel/reduce-the-file-size-of-your-excel-spreadsheets)
covers picture compression, retained image-editing data and saved pivot source
caches. A pivot cache can retain source data for later use. Reducing what is
saved can change refresh requirements; removing image-editing data can also
remove the ability to restore an earlier image state.

The same guide describes binary workbook format as another size-reduction
option. A format change still needs compatibility checks with the tools that
consume the file. No percentage saving or opening-time improvement is reported
here because no comparison has been recorded for a named workbook.

## Size and data correctness need separate checks

A smaller file is not automatically a correct one. [Excel's automatic date conversion](/excel-changing-numbers-into-dates/)
can change identifiers without producing an unusually large file. Conversely,
a valid workbook can legitimately contain large media or cached datasets.

Space on the computer is another measurement again. [Deleting a file](/deleting-files-not-freeing-disk-space/)
can leave recoverable or retained copies elsewhere, so a smaller workbook and a
larger free-space reading are not interchangeable results.
